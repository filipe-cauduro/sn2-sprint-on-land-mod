# Sprint On Land Mod - Subnautica 2
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Description
**Sprint On Land** is a simple yet essential quality-of-life mod for Subnautica 2. While the game naturally lets you glide through the water, walking on land and inside bases can feel sluggish. This mod allows you to sprint on dry land, dramatically improving your traversal speed when exploring islands or large bases.

It features a smart, dynamic footstep audio throttle to prevent audio spam when moving at high speeds, and fully integrates with the in-game UI via SN2ModSettings!

## Main features
- 🏃 **Land Sprinting:** Move X times as fast on land and inside bases. Automatically disabled while swimming.
- ⚙️ **In-Game Settings Menu:** Full support for SN2ModSettings. Adjust all your mod preferences directly from the game's menu!
- ⌨️ **Hold or Toggle:** Configure whether you want to hold down the sprint key or press it once to toggle sprinting on/off.
- 🎮 **Customizable Keybinds:** Supports primary and secondary keys out of the box (defaults to both shift keys).
- 🎧 **Dynamic Audio Pacing:** Automatically throttles footstep sound effects while sprinting so they don't overlap or spam your ears, preserving immersion.

## Installation instructions
1. Make sure you have downloaded and installed **UE4SS** for Subnautica 2.
2. Download the latest version of the `SprintOnLandMod.zip` file from the Files tab.
3. Extract the contents directly into your `Subnautica2\Binaries\Win64\ue4ss\Mods\` folder.
4. (Optional but highly recommended) Install **SN2ModSettings** manage this mod from the main menu!

## Requirements
- **UE4SS:** Essential framework to run Lua mods.
- **SN2ModSettings:** (Optional, but required if you want to use the in-game UI to configure the mod). If you don't install it, you can still edit `Scripts/config.lua` manually.
